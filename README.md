# 🐍 Snake Game

A classic Snake Game built using **HTML, CSS, and JavaScript** as a hands-on JavaScript practice project. The game features a grid-based board where the player controls a snake, collects randomly spawned food, and grows in length with every food item consumed.

## 🎮 Features

- **Snake Movement:** Control the snake as it moves across the game board.
- **Food Consumption:** Collect food items to increase the snake's length.
- **Snake Growth:** The snake grows by one segment every time it consumes food.
- **Random Food Respawning:** Food automatically appears at random positions on the grid.
- **Live Score:** Displays the player's current score and updates as food is collected.
- **High Score Tracking:** Saves the highest score using Local Storage and updates it whenever a new record is achieved.
- **Timer:** Includes a timer to track the duration of each game.
- **Grid-Based Game Board:** A structured grid where the snake moves, grows, and interacts with food.
